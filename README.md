# Claude Code Initial Token Cost Simulation

This example simulates the "initial token cost" concept for AI code assistants like Claude Code, as discussed in the article. It demonstrates how a significant fixed token amount is consumed upfront for system context, even before a user types their query. The script calculates the total tokens for a request by summing this initial cost and the tokens from the user's input.

## Language

`python`

## How to Run

Save the code as `main.py`. Run from your terminal: `python main.py`. Enter a code-related query when prompted.
